I am planning to create three tools for the MCP server. The first is **check_inventory**, which will read the inventory table and check how many of a certain product and size are in stock. This will help with tickets 101 and 103, and it will return the SKU, size, and quantity available. The second is **get_product_pricing**, which will read the pricing table and find the cost and list price of a product. This will help with ticket 103, and it will return the SKU, unit cost, and list price. The third is **get_lease_details**, which will read the leases table and find the important information about a lease. This will help with ticket 102, and it will return the lease ID, landlord, rent amount, and due date.
